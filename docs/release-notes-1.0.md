**Your Downloads had a big night. Hangover cleans up in the morning.**

First release of Hangover, a free menu-bar app that tidies your Desktop and Downloads.

- Moves files into folders by rules you can edit in the app (extension, name starts with, name contains).
- Waits a day: anything from today stays put until tomorrow.
- Never deletes and never overwrites. Leaves files that look like keys or passwords alone and tells you about them.
- Sorts hourly, at login and on wake, with a preview before anything moves.
- Starter rules for screenshots (including `SCR-` screenshot files), installers, archives, images, videos, audio, PDFs and documents.
- Import and export rules as JSON.

**Install:** download `Hangover.zip` below, unzip, drag Hangover to Applications and open it. macOS will block the first open because the app isn't notarized by Apple: go to **System Settings → Privacy & Security** and click **Open Anyway**. See the README for the step-by-step guide.

Requires macOS 13 or later · Apple silicon and Intel.
